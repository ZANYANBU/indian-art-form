# Sangam · Warli × Kalamkari Fusion

**21LEM301T Indian Art Form · CLA-I Assignment 3 · Regional Painting Fusion Project (CO2)**

A digital fusion artwork that combines the geometric figures of **Warli** painting (Maharashtra) with the floral motifs and ornamental borders of **Kalamkari** (Andhra Pradesh). The artwork is drawn procedurally as SVG in the browser.

## What is in the artwork
- **Kalamkari:** tree of life with lotus crown, rosette flowers, peacocks, scalloped central medallion, four-sided vine border, corner paisleys, side creepers
- **Warli:** tarpa dance ring, sun and moon, trees, huts, birds, farmers, deer, oxen and peacocks, corner vignettes

## Features
- Live studio: three palettes (terracotta wall, ivory cloth, indigo vat)
- Toggle every layer, or show Warli only / Kalamkari only
- Regenerate the scene and change the number of dancers
- Export PNG (2400 × 2400) or SVG
- Side-by-side comparison of both styles and a comparison table
- Ready-made project description and 10 presentation points with copy buttons

## Run
No build or backend. Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server
```

## Tech
HTML, CSS, vanilla JavaScript and SVG. All artwork is original and generated in `art.js`.
