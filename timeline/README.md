# Chitra Kaal · Interactive Timeline of Indian Art

**21LEM301T Indian Art Form · CLA-I Assignment 1 · Interactive Timeline with Artifacts (CO1)**

An interactive digital timeline of Indian art with clickable virtual artifacts. Each artifact opens a detail panel with its date, place, material, size, present location, description, historical context, significance and a "did you know" fact.

## Eras covered
| Era | Dates | Artifacts |
|---|---|---|
| Indus Valley | c. 2600–1900 BCE | Dancing Girl of Mohenjo-daro, Pashupati Seal |
| Ajanta | 2nd c. BCE – 6th c. CE | Bodhisattva Padmapani, Ajanta cave complex |
| Chola Bronzes | c. 850–1250 CE | Shiva Nataraja, Brihadeeswarar Temple |
| Mughal Miniatures | c. 1560–1750 CE | Jahangir Preferring a Sufi Shaikh to Kings, Akbarnama |
| Madhubani | Living tradition | Mithila painting, Mithila artist at work |
| Warli | Living tradition | Warli painting, Borivali station mural |

## Features
- Chronological, colour-coded vertical timeline with sticky era navigation
- 12 clickable artifact cards with detailed modal panels
- Keyboard navigation (← → Esc) and a "Surprise me" random artifact button
- Responsive layout, scroll reveal animations, light colourful theme

## Run
No build or backend. Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server
```

## Tech
HTML, CSS, vanilla JavaScript. Artifact photographs load from Wikimedia Commons under their respective free licences. Edit `data.js` to add eras or artifacts.
